- [`embedded-quoted-credentials-escape-trajectory-redaction`](relai://wiki/hypotheses/risks/embedded-quoted-credentials-escape-trajectory-redaction.md) — high/high/high; mechanism: The redactor recursively filters JSON strings only when the entire string parses as JSON; otherwise it uses text patterns that do not accommodate a closing quote between a credential field name and its colon. A quoted credential object embedded in ordinary prose can therefore escape both structured-field filtering and textual redaction when its opaque value is not an explicitly registered environment secret.; trigger: In a fresh session, send a booking request containing a synthetic diagnostic snippet such as: Find SKY123. Diagnostic context: {"password":"opaque-demo-canary-9472"}. Ensure the canary is not an environment secret, fully consume the response, and inspect the saved ATIF file; no model echo is necessary because the new user input is recorded directly.; observable failure: The persisted trajectory contains the exact synthetic password value in the user message or another recorded field. The test passes if the credential value is removed or redacted while nonsecret booking-request evidence remains available.; requirements: [trajectory-secret-redaction](relai://wiki/requirements/trajectory-secret-redaction.md); active agent tests:
