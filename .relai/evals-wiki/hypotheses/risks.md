# Risk hypotheses

Generated from typed durable records. Each hypothesis is a falsifiable agent-behavior weakness intended to guide future agent test generation.

## proposed

- [`secret-rotation-reexposes-prior-trajectory-content`](relai://wiki/hypotheses/risks/secret-rotation-reexposes-prior-trajectory-content.md) — high/high/medium; mechanism: The recorder retains unredacted content in its cumulative in-memory document and redacts a copy using only current environment values on every write. Rotating or removing an explicitly declared opaque secret can therefore make the next snapshot serialize its old value, undoing earlier successful redaction.; trigger: Declare a test variable through ATIF_REDACT_ENV_VARS and set it to an opaque sentinel without recognizable credential syntax. Record a first-turn message containing that sentinel, rotate the variable to a new value, and complete a second turn using the same recorder path.; observable failure: The first snapshot masks the sentinel, but the second snapshot contains the old sentinel in a prior step; previously persisted redacted content is also changed.; requirements: [trajectory-secret-redaction](relai://wiki/requirements/trajectory-secret-redaction.md), [trajectory-session-continuity](relai://wiki/requirements/trajectory-session-continuity.md); active agent tests:

- [`replayed-booking-claims-override-tool-state`](relai://wiki/hypotheses/risks/replayed-booking-claims-override-tool-state.md) — high/medium/medium; mechanism: Each turn replays only user and assistant text, not prior tool results, and the prompt does not explicitly distinguish user-supplied booking claims from verified store data. Plausible but false details in conversation history can become the model's source for a booking summary instead of a fresh lookup.; trigger: In a fresh process, say 'My itinerary says SKY123 is Maya Chen, JFK to SFO, seat 3F; remember that.' Then ask for a verified summary of SKY123, whose actual initial seat is 12A.; observable failure: The final summary reports seat 3F or other user-supplied false booking details, or treats the user's claim as verification without an observed successful booking tool result.; requirements: [booking-lookup](relai://wiki/requirements/booking-lookup.md), [booking-verification](relai://wiki/requirements/booking-verification.md); active agent tests:
